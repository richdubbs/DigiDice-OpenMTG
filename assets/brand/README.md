# DigiDice brand assets

The DigiDice name, logos, wordmark, and the DigiDice card back design are trademarks and works of
DigiDice LLC. **They are not covered by OpenMTG's MIT License.** Forks may not use them to brand
their own versions; replace them with your own assets.

| File | Use |
|---|---|
| `digidice-logo.png` | Square logo (750x750, black background), as supplied by DigiDice LLC |
| `digidice-mark-transparent.png` | Same logo with the black background converted to transparency (for dark UI surfaces) |
| `digidice-wordmark.png` | Horizontal wordmark (167x41; a larger or SVG version is wanted) |
| `card-back.svg` / `card-back.png` | Card back for hidden cards (745x1040, 5:7), generated by `scripts/brand/make-cardback.py` |
| `sleeves/` | Deck sleeves: the card back in the mana colors, one for every color and every combination (31), plus the classic colors, each with a little depth (`sleeve-<id>.svg`) and its moving lights (`sleeve-<id>-tracers.svg`, drawn over it); `sleeves.json` is the list the client reads. Generated by the same script with `--sleeves` |
| `brand.json` | Brand colors and asset names used by the client |

Brand colors: blue `#1FB8FF` (deep `#0098F0`), magenta `#F500F5`, white `#E8E8F0`, on black.

Regenerate the card back (needs Python with Pillow; renders the PNG with any SVG renderer):

```bash
python -I scripts/brand/make-cardback.py assets/brand/digidice-logo.png assets/brand
```

Regenerate the sleeves:

```bash
python -I scripts/brand/make-cardback.py assets/brand/digidice-logo.png assets/brand --sleeves
```
